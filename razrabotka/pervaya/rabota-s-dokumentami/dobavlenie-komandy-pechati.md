---
order: 1
title: Добавление команды печати
---

При разработке новых документов нужно добавлять возможность формирования печатных форм стандартными средствами (подключить к БСП). 

Для этого нужно:

1. **В Модуль менеджера добавить следующий код:**

   ```1c
   // Заполняет список команд печати.
   // 
   // Параметры:
   //   КомандыПечати - ТаблицаЗначений - состав полей см. в функции УправлениеПечатью.СоздатьКоллекциюКомандПечати
   //
   Процедура ДобавитьКомандыПечати(КомандыПечати) Экспорт
   
   	КомандаПечати = КомандыПечати.Добавить();
   	КомандаПечати.МенеджерПечати	= "Документ.ВИД_ДОКУМЕНТА";
   	КомандаПечати.Идентификатор		= "НазваниеПечатнойФормы";
   	КомандаПечати.Представление		= НСтр("ru = 'Название печатной формы'");
   	КомандаПечати.Порядок			= 1;
   	
   КонецПроцедуры
   
   Процедура Печать(МассивОбъектов, ПараметрыПечати, КоллекцияПечатныхФорм, ОбъектыПечати, ПараметрыВывода) Экспорт
   	
   	Если УправлениеПечатью.НужноПечататьМакет(КоллекцияПечатныхФорм, "НазваниеПечатнойФормы") Тогда
   		УправлениеПечатью.ВывестиТабличныйДокументВКоллекцию(КоллекцияПечатныхФорм,
   															"НазваниеПечатнойФормы",
   															"Название печатной формы",
   															ПечатьДокумента(МассивОбъектов, ОбъектыПечати));
   		
   	КонецЕсли;
   	
   КонецПроцедуры
   
   //Здесь описываем печатную форму объекта
   Функция ПечатьДокумента(МассивОбъектов, ОбъектыПечати)
   	ТабДок = Новый ТабличныйДокумент;
   	Макет = ПолучитьМакет("МакетЗапросКП");
   	ТабДок.Вывести(Макет);
   	Возврат ТабДок;
   КонецФункции
   
   ```

2. **На форму документа в процедуру «ПриСозданииНаСервере» добавить код**

   ```1c
   	// СтандартныеПодсистемы.ПодключаемыеКоманды
   	ПодключаемыеКоманды.ПриСозданииНаСервере(ЭтотОбъект);
   	// Конец СтандартныеПодсистемы.ПодключаемыеКоманды
   ```

3. **На форму документа в процедуру «ПриЧтенииНаСервере» добавить код**

   ```
   	// СтандартныеПодсистемы.ПодключаемыеКоманды
   	ПодключаемыеКомандыКлиентСервер.ОбновитьКоманды(ЭтотОбъект, Объект);
   	// Конец СтандартныеПодсистемы.ПодключаемыеКоманды
   ```

4. **В некоторых конфигурациях необходимо добавить вид документа в Объекты печати, для этого в общий модуль «УправлениеПечатьюПереопределяемый» в метод «ПриОпределенииОбъектовСКомандамиПечати»  добавить код**

   ```
   	СписокОбъектов.Добавить(Документы.НазваниеДокумента);
   	СписокОбъектов.Добавить(Справочники.НазваниеСправочника);
   
   ```

5. **Если не добавляется команда печати, тогда в Командную панель документа добавить следующие группы:**

   -  ГруппаКнопкиКоманднойПанели - Вид: Группа кнопок, Источник команды: Форма

      -  ГруппаВажныеКоманды - Вид: Группа кнопок (Источник команд оставить пустым)
