title: Список файлов
---

Во все документы, связанные с исполнением обязательств по проектам, добавляем динамический список **СписокФайлов**.

Все файлы разделяются по Видам. Для этого создан новый справочник **Виды файлов**.

**СписокФайлов** позволяет отобразить список файлов по их видам.

Все виды файлов также версионируются с помощью отдельного Регистра сведений.
