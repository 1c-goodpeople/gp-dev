## Описание

Во все документы, связанные с исполнением обязательств по проектам, добавляем динамический список **СписокФайлов**, отображающий присоединенные файлы, разделенные по видам.

### Справочник Виды файлов

Для разделения файлов по видам создан новый справочник **Виды файлов**. Вид файлов содержит в себе наименование, список типов документов, для которых он используется, а также Номер картинки, который используется для вывода коллекции картинок для соответствующего вида.

### Версии файлов

Все виды файлов также версионируются с помощью отдельного Регистра сведений **Файлы объектов процесса** со следующей структурой:

**Измерения:**

-  **Владелец** \- Определяемый тип «Предмет обработки документов», в который входят все документы, участвующие в работе с проектами. Владелец файла. Сделан отдельным измерением, чтобы упростить процесс получения данных из запросов.

-  **Вид файла** - Справочник Вид файла

-  **Версия - Число** - Номер версии файла, который инкрементируется с каждой новой записью объекта.

**Ресурсы:**

-  **Файл** - Определяемый тип «Присоединенный файл» Ссылка на присоединенный файл

Запись новых файлов производится через общий модуль УПРД\_РаботаСФайламиВызовСервера

## Программная реализация

В общий модуль **УПРД\_РаботаСФайлами** в области **ФайлыСВерсиями** добавлен метод УстановитьНастройкиСпискаФайловДокументаПоВидам, который вызывается При создании на сервере формы документа.

Здесь переопределяется текст запроса динамического списка с файлами.

На форму документа выводится динамический список с пустыми путями к данным.
