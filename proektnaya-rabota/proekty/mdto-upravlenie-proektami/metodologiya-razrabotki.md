## Ядро системы

За ядро системы взята готовая подсистема **Процессы обработки документов**, которая позволяет создавать собственные правила поэтапной обработки документов в виде преднастроенных шаблонов процессов обработки документов.

**Документация по подсистеме:** <https://its.1c.ru/db/bgupoddoc#content:3:hdoc>

## Основные объекты

Для организации маршрутизации бизнес-процессов в Системе создаются учетные документы, к которым подключаются Шаблоны обработки документов:

-  Входящее поручение

-  Проект

-  Запрос Коммерческого предложения

-  Проект договора

-  Карточка ВФК (внутреннего финансового контроля)

-  Претензионно-исковая работа
