### Реализовать возможность ведения этапов проектов

Реализовать возможность внесения этапов исполнения обязательств по договорам в табличную часть Этапы. Таблица должна содержать следующий реквизитный состав:

| **Название поля** | **Тип поля**        | **Комментарий**             |
|-------------------|---------------------|-----------------------------|
| Проект            | Документ Проект     | Ссылка на карточку Проекта  |
| Договор           | Справочник Договоры | Ссылка на карточку Договора |
| Номер этапа       | Число               |                             |
| Название этапа    | Строка (250)        |                             |
| Сумма             | Число               | Лимит этапа договора        |
| Дата начала       | Дата                |                             |
| Дата окончания    | Дата                |                             |

В документе Проект создать вкладку (если его нет) «Этапы и сроки» и поместить таблицу туда.

### Реализовать возможность отслеживания контрольных сроков договора

Реализовать табличную часть Контрольные сроки, которые в разрезе договоров хранят контрольные действия и сроки исполнения. Таблица должна содержать следующий реквизитный состав:

| **Название поля**      | **Тип поля**                              | **Комментарий**                                                   |
|------------------------|-------------------------------------------|-------------------------------------------------------------------|
| Проект                 | Документ Проект                           | Ссылка на карточку Проекта                                        |
| Договор                | Справочник Договоры                       | Ссылка на карточку Договора                                       |
| Контрольное действие   | Справочник Контрольные действия договоров | Заполняется Администраторами Системы                              |
| Дата начала            | Дата                                      | По умолчанию устанавливает Дату начала договора, есть возможность |
| Срок исполнения        | Дата                                      |                                                                   |
| Дополнительное задание | Документ Дополнительное задание           |                                                                   |

Табличная часть должна быть выведена в карточку проекта в разделе Договоры, а также реализовать возможность отображения списка контрольных сроков из карточки Договоров.

В документе Проект создать вкладку (если его нет) «Договоры» и поместить таблицу туда.

Также реализовать возможность прикрепления неограниченного количества файлов произвольных форматов к карточке документа.

### Прикрепление файлов

Документ «Документ по исполнению» должен иметь возможность прикрепления неограниченного количества файлов произвольных типов. Файлы должны разделяться по соответствующим им видам (записываться в Регистр).

### Включить документ «Документ по исполнению» в бизнес-процесс обработки поручений

Реализовать запуск этапа Исполнение обязательств (для документа Документ по исполнению). Реализовать возможность Администраторам системы, при необходимости, вносить изменения в маршруты и устанавливать условия, по которым этапы могут запускаться или пропускаться, а также изменять наименования этапов и результатов их исполнения.
