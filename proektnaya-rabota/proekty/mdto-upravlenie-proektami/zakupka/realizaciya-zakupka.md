### ОКВЭД для Контрагента

### Настройки бизнес-процессы Проекта по Закупке

После завершения Инициализации проекта и получения всех КП запускаются следующие этапы обработки документа Проект:

#### Подтверждение полученных КП

<highlight color="blue">**Ответственный за закупку**</highlight> по полученному поручению проверяет прикрепленные в ответ на запросы КП на корректность. При наличии замечаний пользователю доступна процедура возврата поручения на доработку обратно Ответственному исполнителю за проект с описанием замечаний.

При необходимости, Ответственный за закупку должен иметь возможность **самостоятельно создавать новые карточки Запроса КП** и произвести полный процесс бизнес-процесса аналогично этапу Инициализация проекта, исполняемым Ответственным исполнителем по проекту.

В рамках подтверждения полученных КП Ответственному за закупку должна быть возможность внесения изменений в карточку Проекта.

Завершением исполнения поручения должна являться команда «<highlight color="green">**Полученные КП подтверждены**</highlight>», установленная на форме карточки Проекта. При выявлении замечаний по полученным КП, по команде «<highlight color="purple">**Вернуть на доработку**</highlight>» поручение возвращается Ответственному по исполнению проекта на этап Запрос и получение КП.

#### Протокол НМЦД

Ответственный за НМЦД подтверждает предложенную НМЦД/ЦД, путем приобщения к проекту файлов протокола расчета НМЦД/ЦД, а также расчета НМЦД/ЦД.

Определение вида способа определения НМЦД или ЦД осуществляется по следующим условиям:

-  Для конкурентной процедуры – НМЦД

-  Для единственного источника, если цена до 600 тысяч ЦД

-  Для единственного источника и проведении котировочной сессии – НМЦД

-  Для «Иные закупки по 25 разделу ПОЗ» - ЦД

При выборе вида исполнителя Иные закупки по 25 разделу ПОЗ, поручение прикладывания и подтверждения ЦД не инициируются, а процесс двигается дальше.

Завершением исполнения поручения должна являться команда «<highlight color="green">**Протокол НМЦД/ЦД прикреплен**</highlight>».

#### Формирование Проекта договора/Закупочной документации

<highlight color="blue">**Ответственный за закупку**</highlight> получает поручение, в рамках которого заполняется карточка Проекта договора/Закупочной документации. Процесс запускается <highlight color="blue">Ответственным за закупку</highlight> и заключается в выборе контрагента (если требуется), заполнении карточки договора/Закупочной документации и прикрепление файлов Проекта договора/Закупочной документации.

Завершением исполнения поручения должна являться команда «<highlight color="green">**Сформирована Закупочная документация/Проект договора**</highlight>».

#### Согласование Закупочной документации/Проект договора

<highlight color="blue">**Ответственный за закупку**</highlight> начинает процесс по согласованию Проекта договора/Закупочной документации путем выбора регламента согласования из шаблонов маршрутизации, сформированные Администратором Системы.

Ответственны за согласование получает поручения, в рамках которых производит процедуру согласования Проекта договора/Закупочной документации. Завершением исполнений поручений должна являться команда «Согласовано».

Завершением исполнения поручения согласования Проекта договора/Закупочной документации Ответственным за закупку должна являться команда «<highlight color="green">**Сформирована Закупочная документация/Проект договора**</highlight>».

#### Проведение конкурентной процедуры

При необходимости проведения конкурентной процедуры (устанавливается галочкой в карточке Проекта) <highlight color="blue">**ответственный за закупку**</highlight> получает соответствующее поручение. Процедура проводятся Ответственным за закупку в сторонней информационной системе.

По итогу проведения конкурентной процедуры Ответственный за закупку подтверждает их завершение путем заполнения вводных данных в раздел «Закупка» карточки Проекта в соответствии с представленным описанием полей.

Завершением исполнения поручения согласования Проекта договора/Закупочной документации Ответственным за закупку должна являться команда «<highlight color="green">**Завершена конкурентная процедура**</highlight>».

#### Проведение котировочной сессии

При необходимости проведения котировочной сессии (устанавливается галочкой в карточке Проекта) <highlight color="blue">**ответственный за закупку**</highlight> получает соответствующее поручение. Процедура проводятся Ответственным за закупку в сторонней информационной системе.

По итогу проведения котировочной сессии Ответственный за закупку подтверждает их завершение путем заполнения вводных данных в раздел «Закупка» карточки Проекта в соответствии с представленным описанием полей.

Завершением исполнения поручения согласования Проекта договора/Закупочной документации Ответственным за закупку должна являться команда «<highlight color="green">**Завершена котировочная сессия**</highlight>».
