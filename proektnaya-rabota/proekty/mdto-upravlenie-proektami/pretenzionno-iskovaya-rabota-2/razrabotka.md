### Реализовать учетный документ Претензионно-исковая работа

Создать новый учетный документ «Претензионно-исковая работа», хранящий в себе следующий реквизитный состав:

| **Название поля**                                                      | **Тип поля**            | **Комментарий**                                                                                         |
|------------------------------------------------------------------------|-------------------------|---------------------------------------------------------------------------------------------------------|
| Дата                                                                   | Дата                    | Дата начала процесса претензионной-исковой работы                                                       |
| Договор                                                                | Справочник Договоры     | Ссылка на карточку Договора (устанавливает автоматически при создании на основании из карточки Проекта) |
| Автор                                                                  | Справочник Пользователи | Пользователь, создавший карточку документа                                                              |
| Комментарий                                                            | Строка (неограниченная) |                                                                                                         |
| Наша роль                                                              | Выбор из списка         | Должник / Взыскатель                                                                                    |
| Дата суда первой инстанции                                             | Дата                    |                                                                                                         |
| Дата суда Апелляционной инстанции                                      | Дата                    |                                                                                                         |
| Дата суда Кассационной инстанции                                       | Дата                    |                                                                                                         |
| Дата суда Кассационной инстанции в Верховном Суде Российской Федерации | Дата                    |                                                                                                         |

### Прикрепление файлов

Документ Претензионно-исковая работа должен иметь возможность прикрепления неограниченного количества файлов произвольных типов. Файлы должны разделяться по соответствующим им видам (записываться в Регистр).

### Включить документ Претензионно-исковая работа в бизнес-процесс обработки поручений

Реализовать запуск этапа претензионно-исковая работа. Реализовать возможность Администраторам системы, при необходимости, вносить изменения в маршруты и устанавливать условия, по которым этапы могут запускаться или пропускаться, а также изменять наименования этапов и результатов их исполнения.
