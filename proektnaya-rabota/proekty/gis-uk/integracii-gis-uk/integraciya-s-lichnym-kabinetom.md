Кадровая система ГИС Управления кадрами по запросам получает и возвращает данные по организациям.

В системе реализованы интеграции по следующим наборам данных:

## **Структура предприятий**

ГИС: Управления кадрами  производит обмен данными организационной структуры организаций с системой Личный кабинет сотрудника. \
Позволяет по запросу получить справочную информацию по всем организациям, заведенным в системе ГИС УК

**Опубликовано у нас по адресу**: 192.168.210.195/statehrmcorp_services/hs/personal_account/get_data

**Адрес на шине**: [  http://192.168.200.47:8885/ServiceGatewayBoot/ws/SID0000333](http://192.168.200.47:8885/ServiceGatewayBoot/ws/SID0000333)

**Документация**: [Интеграция между системами “ГИС: Управления кадрами” и СПО “Личный кабинет сотрудника” в разделе структуры организации](https://clck.ru/3CMmEo)

Позволяет по запросу получить справочную информацию всех должностей, заведенным в системе ГИС УК, или должностей по организациям.
