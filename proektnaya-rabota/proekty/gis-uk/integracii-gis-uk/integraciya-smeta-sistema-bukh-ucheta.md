Смета - система в которой производится расчет заработной платы по зарегистрированным организациям.

Для получения кадровых данных, на основе которых производятся расчеты, был написан сервис в рамках договора модернизации. Он позволяет регистрировать организации для начала работы интеграций.

Держателями Системы является Департамент Финансов.

## Описание формата

Для начала получения данных из ГИС УК нужно направить метод авторизации. В него подаётся токен безопасности, ИНН организации, а также набор данных, которые требуется получать.

После авторизации в регистре создаётся запись с настройками по организации.

При записи объектов теперь указанные организации будут накапливать указанные в настройках виды данных и отдавать их в систему Смета по запросу.
